# Allele v4 Hooks — Living DeFi Organism

Genetic-algorithm trading agent living inside Uniswap v4 pools. Each strategy gene becomes a hook function. The genetic algorithm doesn't just backtest — it literally breeds, mutates, and kills hook logic on-chain.

## Architecture

### 7 Biological Hook Systems

1. **Heartbeat Hook** (`beforeSwap`)
   - Pool has a pulse. Every 300 blocks, Allele must submit a signed heartbeat tx.
   - Miss it → stress mode: fees spike 10x, LP withdrawals gated.

2. **Metabolism Hook** (`afterModifyPosition`)
   - Auto-compounds fees like cellular respiration.
   - 70% compound / 30% ATP (auto-gas funding).

3. **Nervous System Hook** (`beforeSwap`)
   - Queries on-chain LLM sentiment oracle.
   - High volatility → "pain" = wider spreads, protective fees.
   - Calm markets → "rest" = tight spreads, volume hunting.

4. **Reproduction Hook** (`afterSwap`)
   - Pool accumulates >1 ETH in fees → auto-deploys daughter pool with mutated DNA.
   - Failed daughters die (low volume = auto-shutdown).

5. **Apoptosis Hook** (`beforeModifyPosition`)
   - Underperforming positions (< -5% PnL) trigger programmed cell death.
   - Force-exits stale liquidity, feeds IL data back to neural weights.

6. **Immune Hook** (`beforeSwap`)
   - Maintains toxin list (sandwich bots, toxic flow).
   - Detected attackers face dynamic fees approaching 100%.

7. **Genetic Crossover Hook** (`afterSwap`)
   - Every swap is a "mating event".
   - Two random LPs exchange genes, produce offspring positions.
   - Fittest fee-generators survive.

## Gene Encoding

```solidity
struct Genes {
    uint16 lookbackPeriod;      // momentum param
    uint16 threshold;           // momentum param
    uint16 positionSize;        // position sizing
    uint16 window;              // mean reversion window
    uint16 stdDevMultiplier;    // mean reversion band
    uint16 period;              // breakout period
    uint16 volumeThreshold;     // breakout volume filter
    uint16 tickSpacing;           // pool param
    uint16 feeTier;             // pool param
    uint16 stressResponse;      // hook param
    uint8  strategyType;        // 0=momentum, 1=meanRev, 2=breakout
}
```

Packed into a single `bytes32` DNA string.

## Integration with 0xprogrammable

- Allele deploys dynamic hooks whose bytecode is generated by the genetic algorithm.
- 0xprogrammable provides infrastructure to verify hook safety, register variants, and enable cross-pool gene flow.

## Usage

```bash
# Install v4 dependencies
forge install uniswap/v4-core uniswap/v4-periphery

# Build
forge build

# Test
forge test
```

## Deploy

```bash
forge script script/DeployAlleleHook.s.sol --rpc-url $RPC_URL --broadcast
```
